# ADR-001: Fixed kernel, generated packs

**Status:** Accepted

## Context

Incumbent platforms serve every manco from one generic engine driven by configuration. Implementations take years. Behaviour is unreadable. Controls can be switched off.

## Decision

Split the platform in two.

- A **kernel** of building blocks with fixed postings, control accounts and invariants. Not configurable.
- A **Tenant Pack** per manco or LISP that holds fund rules, workflows, policies, integrations and tests. Generated by AI from the tenant's documents and history.

## Consequences

- The kernel is tested once and audited once.
- Onboarding is generation, simulation and review, not configuration.
- Some mancos will ask for flexibility the kernel refuses. That refusal is the product.
